01 / Mission brief

Built to make an invisible response visible.

The project explores a core idea in electronics: a sensor turns a physical change into a signal, and a circuit can use that signal to trigger a response.

Project objective / 001
Build a low-cost detector that responds to alcohol vapor with a red LED flash and buzzer alert.
Educational prototype · not a certified breathalyzer
MQ-3Gas sensor module
LM358NComparator stage
5VLow-voltage prototype supply
2 outputsVisual + audible alert
02 / System map

Four stages. One simple signal chain.

The sensor provides the input, the comparator helps make a threshold decision, and the Arduino controls the outputs.

STAGE 01
⌁

Sense

The MQ-3 module responds to alcohol vapor and provides an analog output signal.

STAGE 02
⊞

Compare

The LM358N compares the sensor voltage with an adjustable reference from a 10 kΩ potentiometer.

STAGE 03
⌘

Decide

The Arduino reads the sensor on A0 and comparator status on D2 to decide whether to activate the warning.

STAGE 04
◉

Alert

When the selected threshold is crossed, the red LED lights and the buzzer sounds.

04 / Hardware blueprint

Meet the parts behind the response.

Use the labels printed on your actual modules and verify every connection before powering the breadboard.

COMPONENT 01 / INPUT

MQ-3 alcohol sensor

Responds to alcohol vapor and provides an analog output (AO) for the Arduino and comparator input. The DO pin is not used in this design.

VCC → 5VGND → GNDAO → A0 + pin 3
COMPONENT 02 / COMPARATOR

LM358N + 10 kΩ pot

Provides a comparison stage. The potentiometer sets a reference voltage, while the sensor signal is connected to the non-inverting input.

Pin 8 → 5VPin 4 → GNDPin 1 → D2
COMPONENT 03 / CONTROLLER

Arduino Uno

Reads the analog sensor value on A0, checks the comparator output on D2 and controls the warning outputs.

A0 / SensorD2 / ComparatorD7 / LEDD8 / Buzzer
COMPONENT 04 / OUTPUT

Red LED + active buzzer

The LED provides a visible warning and the active buzzer provides sound. The LED must have a series current-limiting resistor.

D7 → 220 Ω → LEDD8 → Buzzer +Common GND

Build note / before power-on

One ground. Correct pins. USB last.

Keep the Arduino, MQ-3 module and LM358N on a shared ground. Double-check the IC notch and pin numbers, LED polarity, resistor and buzzer connections before connecting USB.
